# 자취방 서바이벌

도트 그래픽으로 만든 서바이벌 게임이다. 자취방에 끝없이 몰려오는 바퀴벌레, 쓰레기봉투, 녹물, 곰팡이를 살림살이로 막으며 버티는 서바이벌 게임이다. 정해진 끝이 없고, 크루마다 가장 오래 버틴 시간으로 순위를 매긴다.

서비스와 분리된 정적 사이트라 빌드 없이 Vercel에 그대로 올린다.

## 조작

| 기기   | 이동                            | 기타                               |
| ------ | ------------------------------- | ---------------------------------- |
| 휴대폰 | 화면 아무 곳이나 누른 채 드래그 | 공격은 자동                        |
| 컴퓨터 | WASD 또는 방향키(한글 입력 상태에서도 동작) | 레벨업 선택 1, 2, 3 / 일시정지 Esc |

선택창에서 **안 고를래요**를 누르면 현재 제안을 받지 않는다. 쌓인 보상이 더 있으면 다음 선택창이 열린다.

게임을 시작하면 8비트 배경음악이 반복 재생된다. 보스 전투에서는 템포가 올라가고, 공격·처치·피격·경험치·아이템·보물상자·진화에 효과음이 나온다. 시작 화면과 게임 오른쪽 위의 ♪ 버튼은 배경음악, FX 버튼은 효과음을 각각 켜고 끈다. 두 설정은 브라우저에 따로 저장되며, 일시정지하거나 다른 탭으로 이동하면 소리도 멈춘다.

바닥의 드롭 아이템은 투사체 위에 표시된다. 게임이 끝나면 결과 화면에서 이번 판의 무기와 레벨, 완성형, 합체, 패시브, 보물을 확인할 수 있다.

## 능력치

게임을 시작할 때 모두 같은 30점을 치명, 공속, 소환, 보물 네 파트에 나눈다(파트당 최대 20점). 나눈 대로 다음 판에도 기억한다. 모두 같은 점수라 순위는 공정하다.

포인트마다 오르는 기본 수치는 작고, 핵심은 5·10·20점에 열리는 능력이다. 기본 수치는 5·10·20점에 1.1·1.2·1.4배가 된다.

보물 피해는 폭죽, 팝콘 기계, 물파스, 전기장판, 방향제, 빨래집게처럼 보물이 직접 주는 피해와 철수세미의 반사 피해다. 보물이 직접 주는 피해는 공격력에 비례하고 레벨마다 4%씩 세져서 후반에도 쓸모 있다. 보물의 범위는 무기 범위(물티슈 등) 영향을 받는다. 보물은 발동 주기가 핵심이라, 무기 쿨타임(건전지 등)에 보물 파트(1점당 -1%, 10점 -30%)와 태엽 열쇠(최대 -40%)의 주기 감소가 곱해진다(최소 원래 주기의 20%).

예를 들어 20·10으로 나누면 두 파트의 능력 다섯 개가 열리고, 10·10·10이면 세 파트의 능력 여섯 개가 열린다.

기존에 적을 밀어내던 공격은 0.35초 동안 일반 적의 이동 속도를 25%, 정예는 15% 낮춘다(보스 제외). 연타는 지속 시간만 갱신하며 둔화율은 쌓이지 않는다. 수건·장판의 둔화와 겹치면 더 강한 효과만 적용한다. 치명 20점 기절과 얼음틀 빙결은 타격으로 지속 시간을 연장하지 않으며 해제 후 1.2초 동안 서로 재발동하지 않는다. 지속 피해(독·화상·출혈·장판·드라이기·제습기·메가 레이저)는 치명타 피해를 적용하지만 타격 기절·얼음틀 빙결·성냥 발동을 일으키지 않는다. 메가 레이저의 최초 충격 등 직접 타격은 기존 효과를 적용한다. 얼음팩·알람시계의 전체 빙결은 기존 지속 시간을 유지한다.

급소 마스터(치명 20점)는 적을 처치하지 않아도 치명타가 적중할 때마다 반경 90 안의 다른 적에게 해당 피해의 30%를 준다. 지속 피해의 치명타에도 적용한다. 이 추가 폭발에는 치명타·고정 피해·기절·빙결·성냥을 다시 적용하지 않으며, 폭발이 다른 폭발을 연쇄 발동하지 않는다. 치명 10점의 처치 폭발은 별도로 유지한다. 피해는 매번 적용하되 같은 적의 폭발 연출만 0.1초 간격으로 묶어 표시한다.

탱탱볼·도탄 톱날·로봇/스페이스 마린·팽이의 이동 속도는 공속 배율에 비례한다. 커피·과충전·저체력 보너스가 바뀌면 즉시 다시 계산한다. 도탄 톱날은 충돌 반경을 최대 56으로 제한하고 같은 적에게 0.16초보다 자주 적중하지 않는다. 독침 기관총은 같은 적에게 한 발사당 최대 두 발, 거품 지뢰는 여섯 파편의 피해를 하나의 큰 폭발로 모으며, 같은 적에게 0.18초보다 자주 폭발 피해를 주지 않는다. 겹친 락스·소독 장판은 가장 강한 세 장까지만 적용한다.

## 맵

시작 화면에서 자취방(마룻바닥), 욕실(하얀 타일), 부엌(체크무늬 장판), 옥상(초록 방수 페인트 타일) 가운데 하나를 고른다. 바닥 위에 소품은 없고 타일만 다르며, 규칙은 같아서 순위는 맵과 상관없이 함께 매긴다. 고른 맵은 기억해 둔다.

1분마다 바퀴벌레 떼가 사방에서 몰려오고, 90초마다 보스가 나온다. 보스는 왕바퀴(돌진한 뒤 사방으로 알 뿌리기), 쓰레기 산(떨어질 자리를 미리 보여 주는 쓰레기 투척, 쓰러지면 쓰레기봉투 10개), 녹슨 보일러(원형 탄막, 소용돌이 증기, 조준 부채꼴을 번갈아 발사), 대왕 파리(좌우로 흔들리며 날아다니고 날파리를 다섯 마리씩 소환), 세탁기 괴물(멈춰서 탈수하며 소용돌이 탄막을 뿜고 오리를 빨아들임), 전기밥솥(빨간 띠로 증기 줄기 세 개를 겨눴다가 뿜음), 곰팡이 여왕(곰팡이를 부르고 오리 둘레에 포자를 고리 모양으로 떨어뜨림) 순서로 돌아가며, 한 바퀴 돌 때마다 더 세진다. 보스가 화면 밖에 있으면 가장자리에 빨간 화살표로 보이고, 보스가 둘 이상이면 체력 막대도 모두 보인다. 보스를 잡으면 보물 상자가 나오고, 열면 보물을 하나 고른다.

시간이 갈수록 적의 체력, 공격력, 이동 속도, 출현 수가 끝없이 늘어난다. 다만 한 번에 받는 피해는 최대 체력의 25%를 넘지 않아서 한 방에 쓰러지지는 않는다.

7분 55초에 경고 배너와 경고음을 표시하고, 8분부터는 모든 적의 체력이 기존 난이도 대비 1.3배로 오른다. 이후에도 기존 성장 곡선에 분당 8% 복리 배율이 추가된다(8분 1.3배, 10분 약 1.52배, 12분 약 1.77배). 살아 있는 적도 남은 체력 비율을 유지한 채 강화되며, 새 적과 정예·보스에도 적용된다. 경고는 다른 등장 배너보다 우선 표시한다.

8분부터는 일반 적의 정예가 나온다. 바퀴벌레(8:00), 쓰레기봉투(8:30), 녹물 방울(9:00), 곰팡이(9:30), 모기(10:00), 거미(10:30), 날파리(11:00), 상한 우유(11:30), 생쥐(12:00), 나방(12:30), 개미(13:00), 민달팽이(13:30), 양말(14:00), 먼지 토끼(14:30), 비둘기(15:00) 순서로 한 종류씩 풀린다. 정예는 금빛 테두리와 왕관을 쓰고 있고 체력 4배, 공격력 1.5배, 몸집 1.25배이며 경험치를 5배, 아이템을 3배 잘 떨어뜨린다. 섞여 나오는 비율은 15%에서 시작해 분마다 늘어 최대 40%다. 6분부터는 보물과 합체 무기를 상대하도록 체력, 공격력, 나오는 수가 훨씬 가파르게 세지고, 14분부터는 벽처럼 세져서(한 번에 깎이는 체력 상한도 1분마다 8%씩 커진다) 20분 안팎이 한계다. 맞은 뒤 무적은 0.6초, 한 번에 깎이는 체력은 최대 40%다. 보스는 도망만 다녀서는 따돌릴 수 없게 빠르게 쫓아온다. 오리는 아무것도 없어도 1초에 체력이 1씩 찬다.

## 아이템

레벨업할 때마다 3개 중 하나를 고른다. 카드에는 피해, 쿨타임, 공격력 같은 수치가 지금 값에서 얼마나 바뀌는지 적혀 있고, 레벨업마다 한 번 다시 뽑을 수 있다(R). 오른쪽 아래에는 지금 능력치가 보인다(휴대폰에서는 "능력치"를 눌러 연다). 무기는 한 판에 최대 8개(보물 파트 20점이면 5개)까지 가질 수 있고, 다 채운 뒤에도 새 무기는 선택지에 나오고, 고르면 가진 무기 하나를 내려놓고 바꾼다(레벨 1부터, 합체에 쓰인 무기는 내려놓을 수 없음). 바꾸기 싫으면 "그대로 두기"로 원래 카드로 돌아간다. 무기와 패시브는 5레벨까지 올리고, 단백질 셰이크와 운동화만 10레벨까지 올린다.

| 로봇청소기  | 혼자 돌아다니며 가까운 적을 들이받는다     |

레이저와 돌돌이는 가까운 적을 조준한다. 슬리퍼는 출발할 때 표적을 따라 완만히 방향을 틀며 돌아오는 속도도 플레이어를 따라잡을 만큼 빨라진다. 슬리퍼 폭풍은 기존의 여덟 방향 발사를 사용한다. 탱탱볼은 적 쪽으로 출발하고 벽에서 튕길 때 안쪽 적을 향해 방향을 조금 보정한다. 쥐덫은 적의 접근 경로를 예측해 서로 다른 위치에 놓인다. 드라이기는 거리 차이가 작은 적 사이에서 표적이 흔들리지 않도록 조준을 유지한다.

투사체·슬리퍼·탱탱볼은 프레임 사이의 전체 이동 경로로 충돌을 검사하며, 관통은 먼저 만난 적부터 처리한다. 거품 폭발도 실제 접촉 위치에서 발생한다. 전자레인지 파동은 낮은 FPS에서도 지나친 적을 한 번만 맞힌다.

약한 기본 무기의 1~5레벨 수치는 다음과 같다. 전자레인지는 피해 28/35/44/54/66, 발사 간격 2.6/2.4/2.2/2.0/1.8초다. 선풍기는 피해 18/25/33/42/52, 제습기는 초당 피해 18/24/31/39/48이다. 드라이기는 초당 피해 30/39/49/61/76, 사거리 150/165/180/200/220이며 조준 회전 속도도 올렸다. 슬리퍼 속도는 390, 돌돌이는 330이다.

돌돌이는 손잡이·원통·잔상, 슬리퍼는 왕복 색상이 다른 궤적, 쥐덫은 준비 진행과 발동 범위를 표시한다. 선풍기는 휘어진 바람 파면, 전자레인지는 열 파동, 제습기는 흡입 기류, 드라이기는 노즐을 표시한다. 튕김·구름·파동 효과음은 각각 재생 간격을 제한한다.

소환 무기는 로봇청소기와 다섯 종류의 소환 무기로 총 여섯 종류다. 기존 생존 배분은 같은 점수의 소환 배분으로 이전한다. 소환 계열은 체력·방어·회복·부활 보너스를 주지 않는다. 비타민·구급상자 같은 별도 아이템은 기존 효과를 사용한다.

| 소환 무기 | 역할 | 완성형 |
| --- | --- | --- |
| 양말 인형 | 적을 추격해 근접 공격 | 양말 기사단: 주변 적을 함께 때리는 인형 셋 |
| 장난감 드론 | 플레이어를 호위하며 원거리 사격 | 쌍포 드론: 관통탄 두 발씩 쏘는 드론 셋 |
| 태엽 자동차 | 적을 향해 돌진하며 경로를 관통 | 태엽 전차: 돌진 끝에서 충격파를 내는 전차 셋 |
| 장난감 검사 | 적을 추격해 부채꼴로 베고 0.7초 검흔 표시. 피해 24→68, 소환 1→2명, 주기 1.5→1.05초 | 검흔 수호자: 검사 셋, 피해 1.65배·범위 1.2배, 약 200도 베기와 1초 검흔 |
| 화분 정령 | 적중하면 주변에 퍼지는 씨앗탄 | 숲의 수호자: 큰 씨앗 두 발씩 던지는 정령 셋 |

검사의 검흔은 시각 효과이며 추가 지속 피해를 주지 않는다. 한 번의 베기는 범위 안의 적마다 한 번 적중한다.

새 무기도 5레벨과 완성형을 갖고, 무기 슬롯을 사용하며 레벨업 선택지·도감·결과 화면에 표시된다. 소환 피해·이동 속도·사거리·공격 속도는 기존 로봇/스페이스 마린과 소독 강습대에도 적용된다. 범위와 투사체 크기, 일반 공격속도 보너스도 함께 적용한다.

**소환 20점은 전용 패시브 해금 조건이다. 20점 도달 보상으로 별도의 소환수·피해 보너스가 즉시 추가되지는 않는다.** 소환 휘장은 1~5레벨에서 소환 피해 +12/+24/+36/+48/+60%, 증원 호루라기는 1~3레벨에서 각 소환 무기의 소환수 +1/+2/+3이다. 둘 다 레벨업으로 고르며 보물 상자에는 나오지 않는다. 완성형 소환 무기는 기본 셋이며 최대 증원 시 여섯, 여섯 무기를 모두 갖추면 총 36개체다. 추가 고정 피해 패시브는 소환 피해 배율로 증폭되지 않고 실제 타격마다 한 번 적용한다.

| 패시브        | 효과                      |
| ------------- | ------------------------- |
| 운동화        | 이동 속도 증가(10레벨까지) |
| 청소기        | 먼지를 더 멀리서 빨아들임 |
| 비타민        | 최대 체력과 회복력 증가   |
| 보조배터리    | 무기를 더 자주 사용       |
| 향초          | 경험치 증가               |
| 물티슈        | 무기 범위 증가, 드라이기·선풍기 바람 폭 증가 |
| 단백질 셰이크 | 모든 무기의 공격력 증가(10레벨까지) |
| 돋보기        | 날아가는 것들이 커짐      |
| 네잎클로버 | 레벨마다 치명타 확률 +6%p, 최대 +60%(10레벨) |
| 핫소스        | 치명타 피해 증가(기본 150%), 네잎클로버를 가진 뒤에만 나옴 |
| 광택제        | 보물 피해 증가(보물 파트 20점이어야 나옴) |
| 태엽 열쇠     | 보물 발동 주기 감소(최대 -40%, 보물 파트 20점이어야 나옴) |
| 정밀 스프링 | 공속 20점 전용 패시브. 1~5레벨: 치확 -4/-8/-12/-16/-20%p, 타격당 고정 피해 +12/+24/+36/+48/+60 |
| 경량 기어 | 공속 20점 전용 패시브. 1~5레벨: 무기 기본 피해 -15/-30/-45/-60/-75%, 타격당 고정 피해 +6/+12/+18/+24/+30 |
| 균형추 | 공속 20점 전용 패시브. 1~5레벨: 현재 공격력 -15/-30/-45/-60/-75%, 타격당 고정 피해 +9/+18/+27/+36/+45 |

정밀 스프링, 경량 기어, 균형추는 레벨업 선택지에서 얻고 5레벨까지 강화한다. 보물 상자에서는 나오지 않으며 보물 슬롯을 차지하지 않는다. 추가 피해는 공격력·치명타·진화·합체 배율로 늘어나지 않고, 무기가 적을 한 번 맞힐 때마다 더해진다. 독·화상·장판 같은 지속 피해와 공격 보물에는 붙지 않는다. 경량 기어는 단백질 셰이크와 이동·저체력 버프까지 반영한 무기 기본 피해에 감소율을 곱한다. 무기 카드의 피해 수치는 현재 공격력과 감소율을 반영한다. 경량 기어는 공격력 능력치와 고무망치·패시브의 고정 피해, 공격 보물 피해를 깎지 않는다. 균형추는 이동·저체력 버프까지 포함한 현재 공격력을 비율로 줄이고 카드에 실제 변경 전·후를 표시한다. 균형추와 경량 기어가 모두 5레벨이면 일반 무기의 기본·지속 피해는 원래의 6.25%, 공격 보물 피해는 25%가 남는다. 고정 피해는 유지된다. 세 패시브를 모두 5레벨로 올리면 타격당 +135이며, 정밀 스프링의 치확 감소는 고무망치 전환 전에 적용한다.

적이 가끔 떨어뜨리는 아이템도 있다. 같은 종류는 맵에 2개까지만 떨어져 있고, 주워야 다시 떨어진다(보물 상자는 빼고).

| 아이템               | 효과                                   |
| -------------------- | -------------------------------------- |
| 🍜 라면              | 체력 15 회복                           |
| 🧺 청소기 먼지통     | 바닥의 먼지를 모두 끌어온다            |

### 합체 무기

시작 화면의 "도감"에서도 볼 수 있다. 도감에는 합체, 보물, 무기, 패시브, 적, 보스가 규칙 파일의 수치 그대로 나온다.

완성형 두 개를 모두 갖추면 레벨업 선택지에 합체가 가장 먼저 나온다. 합체하면 재료 두 완성품의 개별 공격을 끄고 강화된 합체 공격 하나로 대체한다. 합체 순간 남은 재료 투사체·장판·파동·이펙트도 정리하며, 다른 무기의 공격은 유지한다. 같은 재료는 다른 합체에 다시 사용할 수 없다. 장비 표시와 결과 화면에는 작동 중인 합체만 표시한다. 합체는 한 판에 최대 2개까지 만들 수 있고, 다 채우면 더 이상 선택지에 나오지 않는다.

| 조합                     | 합체 무기   | 효과                                                   |
| ------------------------ | ----------- | ------------------------------------------------------ |
| 탱탱볼 + 전기 파리채     | 번개볼      | 공이 주변 적에게 번개를 쏘고, 벽에 부딪히면 크게 방전  |
| 레이저 포인터 + 선풍기   | 메가 레이저 | 0.7초 충전 후 방향과 발사 위치를 고정해 초대형 빔을 3초간 쏜다. 발사 순간 충격 피해와 섬광·충격음이 나오며, 공속은 발사 후 대기를 줄인다               |
| 스테이플러 + 살충제      | 독침 기관총 | 유도 독침 다섯 발을 바라보는 방향의 앞쪽으로 펼쳐 쏘아 중독시킨다. 스테이플러 대비 기본 발사 속도는 20% 낮다(발사 주기 ×1.25). 탄속은 같고 비행 시간은 0.8초에서 1.6초로 늘어 최대 이동 거리가 2배다. 한 적에게는 같은 발사에서 최대 두 발만 적중한다 |
| 로봇청소기 + 락스        | 소독 강습대   | 강화된 마린 탄환이 적중 위치에 소독 장판을 남긴다    |
| 모기향 + 드라이기        | 화염 고리   | 큰 불씨 고리가 돌고, 주기적으로 화염이 휩쓴다    |
| 슬리퍼 + 돌돌이          | 도탄 톱날   | 톱날 셋이 적 사이로 튕기며 벤다. 같은 적은 0.16초마다 적중하고 출혈은 중첩되지 않는다 |
| 젖은 수건 + 빗자루       | 물걸레 회오리 | 물걸레가 주위를 한 바퀴 크게 휘감아 적을 때리고 느리게 한다 |
| 종이비행기 + 파리채      | 파리채 폭격기 | 종이비행기가 맞힌 자리에 파리채가 함께 내려친다. 파리채는 따로 치지 않는다 |
| 쥐덫 + 세제 거품         | 거품 지뢰   | 쥐덫이 닫히면 여섯 파편의 피해를 모은 거대 거품이 한 번 폭발한다     |
| 전자레인지 + 제습기      | 건조 오븐   | 강화 파동이 두 번 퍼지고, 맞은 적을 느리게 하며 바싹 태운다 |
| 샤워기 + 전기 파리채     | 감전 샤워   | 물줄기가 떨어진 자리에서 전기가 주변 적 셋에게 튄다    |

메가 레이저는 한 발사 위치·방향을 유지하므로 플레이어가 움직여도 빔은 회전하거나 따라오지 않는다. 기본 너비는 240, 범위·투사체 크기를 반영한 최대 너비는 400, 길이는 1100이다. 0.7초 충전과 3초 발사 시간은 고정이며 기본 대기는 1.8초(공속 적용)다. 최초 충격은 레이저 피해의 28배, 지속 피해는 초당 34배이며 추가 고정 피해 패시브는 최초 충격에만 한 번 적용한다. 지속 피해는 프레임 시간에 비례하고 매 프레임 숫자·파편 이펙트를 생성하지 않는다.

### 빌드 전용 보물

아래 여섯 아이템은 보물 슬롯을 차지하며 시작 보물·보스 상자의 보물 선택지에 나온다. 일반 레벨업 패시브와는 별개다. 고정 피해 전용은 공속 20점, 소환 전용은 소환 20점이어야 한다. 지속 피해 전용은 락스·드라이기·제습기, 지속 피해가 있는 합체(독침 기관총·도탄 톱날·건조 오븐·소독 강습대·메가 레이저) 또는 성냥을 가진 뒤 나온다.

| 계열 | 보물 | 효과 |
| --- | --- | --- |
| 고정 피해 | 정밀 저울 | 타격당 고정 피해 +20, 전체 고정 피해 +25% |
| 고정 피해 | 공진 못 | 같은 적을 무기로 직접 6회 맞히면 현재 고정 피해의 2배를 한 번 추가. 고정 피해가 있어야 등장 |
| 지속 피해 | 보온병 | 지속 피해 +40% |
| 지속 피해 | 농축 앰플 | 같은 적에게 지속 피해를 주면 3초에 걸쳐 최대 +60%, 0.5초 끊기면 초기화 |
| 소환 | 지휘봉 | 소환 최종 피해 +35%, 탐색·사격 사거리 +20% |
| 소환 | 행군 북 | 소환 공격 속도·이동 속도 +25% |

정밀 저울은 고무망치와 고정 피해 패시브에도 적용한다. 공진 못의 추가 고정 피해는 치명타·공격력·진화·합체 배율로 늘지 않으며, 추가 피해가 다시 연타 수를 쌓지 않는다. 지속 피해와 보물이 직접 주는 공격은 연타 수에서 제외한다.

농축 앰플은 피해 횟수가 아닌 실제 경과 시간으로 충전하므로 장판을 겹쳐도 빨리 쌓이지 않는다. 프레임 구간의 평균 충전율을 사용한다. 보온병과 최대 농축은 서로 곱해 최대 2.24배이며, 지속 피해의 치명타 피해는 유지하고 타격 기절·빙결은 발동하지 않는다. 소환 보물은 개체 수를 늘리지 않으므로 여섯 소환 무기를 모두 갖추면 최대 36개체다.

## Supabase 연결

1. Supabase 프로젝트를 만들고 SQL Editor에서 `supabase/schema.sql`을 실행한다.
2. Project Settings > API Keys의 Project URL과 publishable 키(예전 anon 키)를 `src/config.js`에 넣는다.

publishable 키는 브라우저에 공개되는 키다. RLS로 기록 추가와 조회만 허용한다. 연결하지 않으면 순위는 그 브라우저에만 저장된다.

### 시즌

순위는 시즌마다 따로 모은다. 지금은 시즌 3이다(2026-11-12, 난이도를 20분 안팎이 한계가 되도록 올리며 새로 시작). 시즌 1·2 기록은 순위 화면의 탭에서 볼 수 있다. 새 시즌을 열려면 `src/leaderboard.js`의 `SEASON`을 올리고 `SEASONS` 맨 앞에 넣으면 된다(데이터베이스는 그대로 둔다). 시즌을 나눌 때 실행한 SQL은 `supabase/2026-11-season-2.sql`에 있다.

## 실행과 배포

```bash
npx serve .

```

## 구조

| 파일                 | 역할                                |
| -------------------- | ----------------------------------- |
| `src/rules.js`       | 난이도, 적, 보스, 무기, 아이템 수치 |
| `src/engine.js`      | 화면과 분리한 게임 진행             |

| `src/main.js`        | 화면 전환, 조작, HUD                |

점수는 브라우저에서 계산해 보내므로 마음먹고 조작하는 것까지는 막지 못한다. 크루끼리 즐기는 용도로 만들었다.
