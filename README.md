# 자취방 서바이벌

자취방에 끝없이 몰려오는 바퀴벌레, 쓰레기봉투, 녹물, 곰팡이를 살림살이로 막으며 버티는 서바이벌 게임이다. 정해진 끝이 없고, 크루마다 가장 오래 버틴 시간으로 순위를 매긴다.

서비스와 분리된 정적 사이트라 빌드 없이 Vercel에 그대로 올린다.

## 조작

| 기기   | 이동                            | 기타                               |
| ------ | ------------------------------- | ---------------------------------- |
| 휴대폰 | 화면 아무 곳이나 누른 채 드래그 | 공격은 자동                        |
| 컴퓨터 | WASD 또는 방향키                | 레벨업 선택 1, 2, 3 / 일시정지 Esc |

## 적

| 적         | 특징                                                | 나오는 시점 |
| ---------- | --------------------------------------------------- | ----------- |
| 바퀴벌레   | 빠르고 많다                                         | 처음부터    |
| 쓰레기봉투 | 느리고 단단하다. 쓰러지면 쓰레기 조각 둘로 갈라진다 | 25초        |
| 녹물 방울  | 거리를 두고 녹물을 쏜다                             | 50초        |
| 곰팡이     | 쓰러진 자리에 밟으면 느려지는 곰팡이 자국을 남긴다  | 80초        |
| 날파리 떼  | 아주 빠르고 약하다                                  | 2분 30초    |

1분마다 바퀴벌레 떼가 사방에서 몰려오고, 90초마다 보스가 나온다. 보스는 왕바퀴(돌진), 쓰레기 산(쓰러지면 쓰레기봉투 10개), 녹슨 보일러(사방으로 녹물 발사) 순서로 돌아가며, 한 바퀴 돌 때마다 더 세진다. 보스를 잡으면 보물상자가 나오고, 열면 두 번 강화한다.

시간이 갈수록 적의 체력, 공격력, 이동 속도, 출현 수가 끝없이 늘어난다.

## 아이템

레벨업할 때마다 3개 중 하나를 고른다. 모두 5레벨까지 올린다.

| 무기      | 효과                                 |
| --------- | ------------------------------------ |
| 🧴 살충제 | 가까운 적에게 약을 뿌린다(처음 무기) |
| 🧹 빗자루 | 주변을 크게 쓸어 밀어낸다            |
| 🧪 락스   | 적이 몰린 곳에 독한 웅덩이를 남긴다  |
| 💧 제습기 | 곁에 오는 적을 계속 말린다           |
| 🏓 파리채 | 가장 센 적을 세게 내려친다           |
| 🩴 슬리퍼 | 던지면 돌아오는 슬리퍼               |

| 패시브        | 효과                      |
| ------------- | ------------------------- |
| 🧤 고무장갑   | 받는 피해 감소            |
| 👟 운동화     | 이동 속도 증가            |
| 🌪️ 청소기     | 먼지를 더 멀리서 빨아들임 |
| 💊 비타민     | 최대 체력과 회복력 증가   |
| 🔋 보조배터리 | 무기를 더 자주 사용       |

적이 가끔 떨어뜨리는 아이템도 있다.

| 아이템               | 효과                                   |
| -------------------- | -------------------------------------- |
| 🍜 라면              | 체력 30 회복                           |
| 🧺 청소기 먼지통     | 바닥의 먼지를 모두 끌어온다            |
| 💨 연막 살충제       | 주변의 적을 모두 쓰러뜨린다(보스 제외) |
| 🧋 아이스 아메리카노 | 10초 동안 빨라지고 무기를 더 자주 쓴다 |

수치는 모두 `src/rules.js`에 있다.

## Supabase 연결

1. Supabase 프로젝트를 만들고 SQL Editor에서 `supabase/schema.sql`을 실행한다.
2. Project Settings > API의 Project URL과 anon public 키를 `src/config.js`에 넣는다.

anon 키는 브라우저에 공개되는 키다. RLS로 기록 추가와 조회만 허용한다. 연결하지 않으면 순위는 그 브라우저에만 저장된다.

## 실행과 배포

```bash
npx serve .
npm test
```

1. 이 폴더를 GitHub 저장소로 올린다.
2. Vercel에서 저장소를 가져오고 Framework Preset은 Other, Build Command와 Output Directory는 비워 둔다.

## 구조

| 파일                 | 역할                                |
| -------------------- | ----------------------------------- |
| `src/rules.js`       | 난이도, 적, 보스, 무기, 아이템 수치 |
| `src/engine.js`      | 화면과 분리한 게임 진행             |
| `src/render.js`      | 캔버스 그림                         |
| `src/main.js`        | 화면 전환, 조작, HUD                |
| `src/leaderboard.js` | Supabase 순위, 미연결 시 로컬 순위  |

주소 끝에 `#debug`를 붙이면 브라우저 콘솔에서 `window.__game`으로 게임 상태를 바꿔 볼 수 있다.

점수는 브라우저에서 계산해 보내므로 마음먹고 조작하는 것까지는 막지 못한다. 크루끼리 즐기는 용도로 만들었다.
